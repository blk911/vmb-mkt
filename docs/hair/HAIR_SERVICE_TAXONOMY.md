# HAIR SERVICE TAXONOMY

**Evidence basis:** Live menus from **Perlino**, **The Place Salon**, **Tulip’s Salon** + identity sample of 90 operators.  
**Caveat:** Three menus cannot fully prove market-wide taxonomy. Categories below are **evidence-derived hypotheses**, not product schema.

## 1. What categories naturally emerge?

From Perlino’s own menu grouping (highest-structure live evidence):

1. Haircuts (+ blow-dry, bangs)
2. Custom Color (lived-in / blonding language; full / partial / mini)
3. Traditional Highlighting (full / partial foils)
4. All Over Color + Glazing (root, roots-to-ends, glaze/gloss/toner)
5. Extensions (keratin + weft; partial / full / extra full; row maintenance)
6. Keratin + Brazilian Blowout Treatments
7. Special Event Styling
8. Conditioning Treatments (brand-tiered)

The Place collapses most of this into priced SKUs with **length tiers** (SHORT / MEDIUM / LONG) and combo names (“Partial HighLight Haircut”).

Tulip’s uses discrete fixed SKUs (cut, color retouch, highlights, balayage/ombre, add-ons).

**Natural cluster count from evidence: 5–8 operational families**, not three.

## 2. Can they be cleanly presented as three client-facing categories?

**Yes, as a client presentation layer — with caveats.**

| Client category | Maps from natural clusters | Evidence strength |
|---|---|---|
| **Cuts & Styling** | Haircuts, blow-dry, bangs, updo, event styling | High (3/3 menus) |
| **Color & Lightening** | Custom color, highlights, all-over, glaze/toner, balayage | High (3/3) |
| **Treatments & Extensions** | Keratin/Brazilian, deep condition, extension install/maintenance | Medium (Perlino strong; Tulip add-on scalp; The Place weak on extensions) |

This three-bucket model is a **UI rollup**, not the operational taxonomy salons use.

## 3. Services that cross categories

| Pattern | Example | Implication |
|---|---|---|
| Color + Cut package | “Full Highlight with Haircut”, “Color Retouch and Haircut” | Finish is often a **package variant**, not a free-floating add-on |
| Color + Blowdry package | “Root Touch-Up + Blowdry” | Same |
| Highlight + base color | “Highlights and Root Color + Cut”, “Color, Highlight with Blowdry” | Combo SKUs common |
| Glaze + cut | “Glaze + Haircut” | Toner/gloss can be standalone or bundled |

## 4. Which categories need distinct option sets?

| Category | Distinct option sets indicated | Evidence |
|---|---|---|
| Cuts & Styling | Length tier (SHORT/MED/LONG); gender/cut type | The Place, Tulip, Perlino |
| Color & Lightening | Coverage tier (mini/partial/full); finish (cut vs blowdry); consultation gate for big change | Perlino, The Place |
| Treatments & Extensions | Density/volume tier (partial/full/extra full); row count; consultation required; product brand tier for conditioners | Perlino |

## 5. Core vs hidden detail

**Core (client-visible SKUs):** haircut, blowout/blow-dry, root touch-up, all-over color, partial/full highlight, balayage (as named SKU or under custom color), keratin/Brazilian (starting at), extension consult/install tiers.

**Hidden / salon-detail (do not force into client UX yet):**
- Exact bowl/ounce chemistry (**NOT OBSERVED** in live sample)
- Stylist-level junior/senior (**NOT OBSERVED**)
- Foil count / extra foils (**MARKET LANGUAGE ONLY** via “full/partial”, not per-foil)
- Brand product choice for deep condition (observed at Perlino — candidate FIXED_OPTION, low operator count)

## Textured / natural / braid / loc / wig

| Pattern | In identity sample? | In live menus? | Recommendation |
|---|---|---|---|
| Operator names suggesting textured/natural (e.g. Black Moon) | Yes (name signals) | **No** | Do **not** erase; treat as **specialist vertical pack** pending menu evidence |
| Braids / locs / silk press / sew-in / wig | Name search intent only | **No** | Defer; not forced into Cuts & Styling |
| Barber / clipper | Yes | Yes (Tulip buzz; Place mens) | Fits Cuts & Styling + optional Barber pack |

**Ruling:** Textured/natural services are **not** proven to need a fourth client category from this dig; they are also **not** absorbed into generic styling. Hold as **specialist service group** until ≥3 menus capture braid/loc/press language.

## Three-category recommendation (tested, not assumed)

**Adopt for client-facing Hair:**

1. **Cuts & Styling**
2. **Color & Lightening**
3. **Treatments & Extensions**

**Do not claim** this is the only natural structure — salons often publish 6–8 sections.

**Specialist groups that do not fit cleanly (preserve separately):**
- Braids / locs / natural / silk press / wig / weave (**evidence gap**)
- Full extension systems with consultation + row/weft economics (**Perlino only — keep, don’t erase**)
- Bridal / event + makeup bundles (**cross-vertical**)
